# Security Policy

## Supported versions

Security fixes are applied to the latest tagged release.

## Reporting a vulnerability

Please do not publish suspected vulnerabilities as public issues. Contact the maintainer privately through the GitHub profile associated with this repository and include reproduction steps, affected versions, and potential impact.

Saturni processes local documents and can connect to a configurable Ollama server. Users should protect remote Ollama endpoints, review retrieved source passages, and avoid indexing secrets that should not be available to the configured model server.
